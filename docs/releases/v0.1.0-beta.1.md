# Far Far West VR — first public beta

Controller aiming, readable menus, and a HUD adapted for the headset. This beta
extends the original Far Far West UEVR profile with independent head look,
controller menu pointing, stabilized aiming, and a growing set of UI corrections.

**Profile and installer only.** The custom UEVR runtime is **not included** while
redistribution permission is arranged. This package currently requires an
existing matching custom runtime. First-time users must wait for its availability;
stock UEVR is insufficient.
[Ask about installation or runtime availability](https://github.com/brifl/FarFarWestVR/issues/new?template=installation.yml)
if unsure.

## Downloads

- **FarFarWestVR-0.1.0-beta.1-Setup.zip** — recommended. Extract All and run
  `Install-FarFarWestVR.cmd`. It checks the selected runtime, installs the profile,
  sets up the game-log link and heat workaround, backs up an existing installation,
  and preserves `tuning.ini`.
- **FarFarWestVR-0.1.0-beta.1-Profile.zip** — for experienced users installing
  manually. Game configuration and the log link still need setup.
- **SHA256SUMS.txt** — checksums for both downloads.

Use these named assets rather than the automatically generated Source code ZIP.
There is no separate DLL download. Follow the
[setup and browser/Windows warning instructions](https://github.com/brifl/FarFarWestVR/blob/v0.1.0-beta.1/docs/SETUP.md).

## Included

- Right-controller aiming, independent head look, an aligned reticle, and adjustable stabilization.
- Point-and-click menus, readable pause/train preview screens, and controller pause/resume.
- Left-stick movement, snap turning, tunable horse steering, and gesture shortcuts for map/horse/utility/photo.
- Three spells on left grip, right grip, and both grips; X for interaction, dialogue, and contextual dropping.
- Vendor, objective, teammate, and tagged-object marker corrections; HUD proportions/margins and separate height tuning.
- Reduced haze, contrast/saturation tuning, and the heat-distortion workaround.

Tested with **Far Far West 0.3.0.7**, **Windows**, **Quest 3**, **Virtual Desktop**,
and **SteamVR/OpenVR**. Requires the game and a PC VR setup. Other combinations
are unverified. Some overlays still need validation; the directional locator is
under investigation. Full hand-position/wrist tracking is planned. Game patches
may require a matching backend update.

UI capture is off in public ZIPs and can be enabled for troubleshooting. No
diagnostics are uploaded automatically.
